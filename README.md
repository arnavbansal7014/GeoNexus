# GeoNexus #
**Descriptions** 

**GEONEXUS** — Intelligent Warehouse Location Optimization Platform

GEONEXUS is a smart warehouse planning and location optimization platform that helps businesses determine optimal warehouse locations based on customer demand, delivery distance, warehouse capacity, fixed costs, and delivery constraints.
It uses mathematical optimization to evaluate warehouse combinations and provides an interactive dashboard with maps, delivery routes, warehouse utilization, cost analysis, and optimization insights.

**Key features:**
Optimal warehouse location selection
Customer demand and order-volume analysis
Warehouse capacity optimization
Delivery-distance and cost minimization
Interactive geographic visualization
Warehouse-to-customer route mapping
Capacity and utilization analysis
Before/after cost comparison
Automated warehouse candidate generation
Interactive Streamlit dashboard

**AI Components**: Python • Streamlit • PuLP • Pandas • NumPy • Folium • OpenStreetMap • AntiGravity • Claude • Grok • Perplexity
